🗺️ PingClab 이용방법

도시 선택부터 인스타 카드 저장까지 — 단계별로 자세히 알려드립니다

1

🏙️ 여행할 도시를 선택하세요

메인 화면 검색창에서 도시 이름을 입력하거나, 아래 도시 카드를 클릭해 선택합니다. 현재 도쿄 · 오사카 · 교토 · 후쿠오카 · 삿포로 5개 도시를 지원합니다.

  • 검색창에 「도쿄」, 「오사카」 등 도시명을 입력하면 자동완성 목록이 나타납니다
  • 도시 카드를 클릭해도 바로 선택됩니다
  • 각 도시별로 큐레이션된 장소 40~50개가 내장되어 있습니다
💡 Tip. 여러 도시를 묶은 여행이라면 도시별로 일정을 따로 만든 뒤 공유 링크를 합쳐서 관리하면 편리해요.
2

📅 여행 기간과 출발일을 설정하세요

여행 일수(2~30일)와 출발 날짜를 입력하면 복귀일이 자동 계산됩니다. 날짜를 설정하면 요일별 휴무 정보와 영업시간 뱃지가 활성화됩니다.

  • 2~7일은 버튼으로 빠르게 선택, 더 긴 일정은 ✏️ 직접 입력
  • 출발일 입력 시 각 관광지에 요일 휴무 경고(🔴)가 자동 표시됩니다
  • 날짜 없이도 일정 생성·공유가 가능합니다
💡 Tip. 월요일 휴관인 박물관, 수요일 휴무인 식당이 많습니다. 날짜를 입력하면 충돌을 미리 확인할 수 있어요.
3

🎨 여행 스타일과 예산 등급을 선택하세요

여행 스타일(커플 · 가족 · 혼자 · 친구)과 예산 등급(알뜰 · 적당 · 여유)을 선택하면 일정 자동 생성의 최적화 기준이 됩니다.

  • 스타일별로 추천 장소 가중치가 다르게 적용됩니다
  • 예산 등급에 따라 하단 예산 바의 숙박비 계산 기준이 바뀝니다
커플 여행 가족 여행 혼자 여행 친구들과 알뜰 적당 여유롭게
4

✨ 일정이 자동으로 생성됩니다

설정을 완료하면 큐레이션 장소들로 최적 동선 일정이 1초 안에 자동 완성됩니다. 각 날짜별로 오전 관광 → 점심 → 오후 관광 → 저녁 슬롯이 채워집니다.

  • 관광지 배치는 이동 거리 최적화 알고리즘(TSP)으로 동선을 자동 정렬합니다
  • 슬롯 상단에 예상 이동 시간과 교통 수단이 표시됩니다
  • 날씨 정보, 예산 합계, 교통 패스 추천도 함께 제공됩니다
💡 Tip. 마음에 들지 않으면 상단 「다시 생성」이 아닌 아래 방법으로 직접 수정하는 게 더 효율적입니다.
5

✏️ 장소를 추가·삭제·교체하세요

왼쪽 사이드바에서 장소를 선택하고 오른쪽 일정 슬롯을 클릭하면 배치됩니다. 드래그로 순서를 바꾸거나, 직접 입력으로 DB에 없는 장소도 추가할 수 있습니다.

  • 장소 추가: 사이드바에서 장소 클릭 → 슬롯 클릭으로 배치
  • 순서 변경: 슬롯을 드래그 앤 드롭으로 위·아래 재배치
  • 날짜 이동: 슬롯의 ↕ 버튼 → 이동할 날짜 탭 클릭
  • 삭제: 슬롯의 ✕ 버튼 클릭 (Ctrl+Z로 실행 취소 가능)
  • 직접 입력: 사이드바 하단 「장소 직접 추가」로 DB 외 장소 등록
  • 외부 검색: 장소명 입력 시 OpenStreetMap 자동 검색 지원
💡 Tip. 사이드바 상단 카테고리 필터(관광·맛집·카페·쇼핑·야경)와 지역 필터를 활용하면 원하는 장소를 빠르게 찾을 수 있어요.
6

🗺️ 지도로 동선을 확인하세요

각 날짜 카드 상단에 지도가 표시되고, 배치된 장소에 번호 마커가 찍힙니다. 동선 최적화 버튼을 누르면 이동 거리가 가장 짧은 순서로 자동 재배치됩니다.

  • 마커를 클릭하면 장소 상세 정보가 표시됩니다
  • Google Maps API 키가 설정된 경우 실제 대중교통 경로와 소요 시간이 표시됩니다
  • 오른쪽 상단 🗺 버튼으로 전체 지도 확대 보기가 가능합니다
  • ⚡ 최적화 버튼: 관광지만 최적 동선 재배치 (식사·카페 슬롯 위치 유지)
7

🏨 숙소·항공·입장권을 예약하세요

각 날짜 하단의 CTA 버튼으로 아고다(숙소), 클룩(입장권·투어), 스카이스캐너(항공)를 바로 연결합니다. 예약 필요 장소에는 🎟 클룩 예약 버튼이 개별 노출됩니다.

  • 🏨 숙소 예약: 해당 날짜의 체크인·체크아웃 날짜가 자동 설정된 아고다 페이지로 이동
  • 🎫 입장권: 클룩에서 해당 도시 입장권 목록으로 이동
  • ✈️ 항공권: 스카이스캐너 인천 출발 해당 도시 검색 페이지
  • 🛡️ 여행자 보험: 하단 배너에서 클룩 보험 가입 가능
💡 Tip. 숙박 지역을 선택하면 (숙소 슬롯 → 지역 드롭다운) 다음 날 동선 최적화의 출발지가 해당 지역으로 설정됩니다.
8

💾 일정을 저장하고 공유하세요

완성된 일정을 링크로 공유하거나, 텍스트로 복사해 카카오톡에 바로 붙여넣기할 수 있습니다. 로그인하면 클라우드에 영구 저장됩니다.

  • 🔗 링크 공유: URL에 일정 데이터를 인코딩해 링크 하나로 전달
  • 📋 텍스트 복사: 날짜·장소·비용이 정리된 텍스트를 클립보드에 복사
  • ☁️ 클라우드 저장: Google 로그인 후 저장 → 다른 기기에서도 불러오기 가능
  • 🖨️ 인쇄: 브라우저 Ctrl+P로 깔끔한 여행 일정표 출력
💡 Tip. 링크를 받은 상대방이 링크를 열면 같은 일정이 자동으로 복원됩니다. 로그인 없이도 공유가 됩니다.
9

📸 인스타그램 캐러셀 카드로 내보내기

완성된 일정을 1080×1350 인스타 카드로 자동 생성합니다. 훅 카드 + 날짜별 지도 카드 + 휴무 안내 카드 + 예산 카드 순서로 구성됩니다.

  • 상단 내비게이션 「⋯ 더보기」 → 「📸 인스타 카드」 선택
  • 날짜별로 지도가 렌더링된 이미지 카드가 순서대로 저장됩니다
  • 브랜드 로고와 도메인 워터마크가 자동으로 삽입됩니다
  • 저장된 이미지를 인스타그램 앱에서 캐러셀로 업로드하면 완성!
💡 Tip. 카드 생성에 30초~1분 정도 소요됩니다. 생성 중 다른 탭으로 이동하지 마세요.

❓ 자주 묻는 질문 (FAQ)

로그인 없이도 사용할 수 있나요?
네, 로그인 없이 일정 생성·편집·공유 모두 가능합니다. 단, 로그인하면 여러 일정을 클라우드에 저장하고 다른 기기에서 불러올 수 있습니다.
지도가 표시되지 않아요.
Google Maps API 키가 설정되지 않은 경우 지도 기능이 제한됩니다. 서비스 관리자에게 문의하거나, 개발자라면 GOOGLE_MAPS_KEY 변수에 키를 입력하세요.
일본 외 다른 나라는 지원하나요?
현재는 일본 5개 도시(도쿄·오사카·교토·후쿠오카·삿포로)를 지원합니다. 다른 나라는 순차적으로 추가할 예정입니다.
내가 직접 추가한 장소가 저장되나요?
네, 직접 입력한 장소 정보는 일정 데이터에 포함되어 공유 링크·클라우드 저장 모두 적용됩니다.
플래너가 갑자기 사라졌어요.
브라우저 로컬 스토리지에 자동 저장됩니다. 페이지를 새로고침하면 상단에 「이전 일정 불러오기」 배너가 나타납니다. 클릭하면 복원됩니다.
